# ReDream AI Thesis LaTeX Workspace

This directory contains the LaTeX source for the master's thesis.

Build:

```bash
make pdf
```

Edit metadata in `metadata.tex`, prose in `chapters/`, figures in `figures/`, and bibliography entries in `references.bib`.

See `../docs/thesis/latex_writing_guide.md` for the chapter plan, writing rules, Zotero workflow, and Google Docs conversion checklist.
